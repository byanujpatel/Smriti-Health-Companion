# Smriti Saathi Hackathon Docs

This folder contains the working plan for **Smriti — Dadi Ka Health Saathi** for the BestPossible.AI Hackathon, August 1-10, 2026.

## The 3 Judging Signals

Every strong submission needs all three:
1. **AI workflow you can show** — not that you used AI, but HOW (tools, order, prompts)
2. **Project someone can actually use** — deployed live URL, public repo, real auth
3. **Social/impact angle** — a specific person with a specific problem, not "for society"

## One-Line Direction

**"Smriti helps families remember what ageing parents forget to mention."**

Dadi speaks one voice note in Hindi. Smriti structures it. Her daughter in Mumbai sees it instantly. The doctor gets a summary. One voice note. Three lives connected.

## Auth Decision

**Guest-first. No forced login.** Anyone can try the product immediately — enter a parent's name and start. Optional Supabase sign-in in Settings for cross-device persistence. This maximises judge trial rate and still satisfies the "real auth" criterion.
